# Modern Calculator Web Application

A modern and interactive calculator web application built using HTML, CSS, and JavaScript. The application performs basic arithmetic operations through a clean and visually appealing glassmorphism user interface, allowing users to perform calculations dynamically without refreshing the page.

## Key Highlights

- Interactive Calculator Application
- Arithmetic Operations Support
- Modern Glassmorphism Design
- Dynamic Calculations
- JavaScript Event Handling
- Responsive User Interface

## How to Run

1. Clone the repository

```bash
git clone https://github.com/Teja2037/calculator-project.git
```

2. Open `calculator.html` in any modern web browser.

3. Use the calculator buttons to enter numbers and operators.

4. Click the `=` button to calculate the result.

5. Use the `C` button to clear the display.

6. Use the `⌫` button to remove the last entered character.
